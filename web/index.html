Device

On the device tap Sync (Bluetooth stays on for 2 minutes), then press Connect here. On USB power the device is always visible.

Charts

Drag to zoom, double click to reset.

Downloaded logs are kept in this browser (IndexedDB), so charts also work offline.
Browser support:
  • Chrome and Edge on Android, Windows, macOS and ChromeOS work.
  • Linux: Chrome with the flag chrome://flags/#enable-experimental-web-platform-features.
  • Firefox and Safari have no Web Bluetooth. On iPhone use a Web Bluetooth browser such as Bluefy.
Nothing leaves this browser: the page talks only to the device.
